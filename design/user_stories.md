# User Stories

## Must Have

1. **Add Semester:** As a student, I want to add a semester so that I can track my grades for that semester.
2. **Add Class:** As a student, I want to add a class so that I can track my grade in that class.
3. **Add Assignment:** As a student, I want to add an assignment so that its grade can be included in my class grade.
4. **Autocalculate Final Grade:** As a student, I want my final class grade to be calculated automatically so that it reflects the grades I have entered.
5. **Calculate Semester GPA:** As a student, I want GradePoint to calculate my semester GPA so that I can see my GPA for an individual semester.
6. **Calculate Overall GPA:** As a student, I want GradePoint to calculate my overall GPA so that I can see my cumulative GPA across semesters.

## Should Have

7. **Edit Semester:** As a student, I want to edit a semester so that I can update information about it.
8. **Delete Semester:** As a student, I want to delete a semester so that I can remove a semester I no longer want to track.
9. **Weighted Class:** As a student, I want to create a class that uses weighted grading so that my grade can be calculated using category weights.
10. **Points Class:** As a student, I want to create a class that uses points-based grading so that my grade can be calculated using points earned and points possible.
11. **Edit Class:** As a student, I want to edit a class so that I can update its information.
12. **Delete Class:** As a student, I want to delete a class so that I can remove a class I no longer want to track.
13. **Edit Assignment:** As a student, I want to edit an assignment so that I can update its information or grade.
14. **Delete Assignment:** As a student, I want to delete an assignment so that it is no longer included in my class grade.
15. **View Complete Transcript:** As a student, I want to view my complete transcript so that I can see my semesters, classes, and grades in one place.
16. **Persistent Data:** As a student, I want my GradePoint data to persist so that my information is still available when I return to the program.

## Could Have

17. **Override Final Grade:** As a student, I want to override a calculated final grade so that I can record a different final grade.
18. **Semester What If:** As a student, I want to enter hypothetical grades for a semester so that I can see how different outcomes would affect my semester GPA.
19. **Class What If:** As a student, I want to enter hypothetical grades for a class so that I can see how they would affect my class grade.
20. **Predict Current Semester GPA:** As a student, I want GradePoint to predict my current semester GPA so that I can see my expected GPA based on my current grades.
21. **Predict End-of-Semester GPA:** As a student, I want GradePoint to predict my end-of-semester GPA so that I can see what my GPA is expected to be after the current semester.
22. **How GPA Is Calculated:** As a student, I want to see how my GPA is calculated so that I can understand how my grades contribute to my GPA.

## Won't Have

23. **Upload Syllabus:** As a student, I will not be able to upload a syllabus for GradePoint to extract class or assignment information.
24. **Enter Final Date/Time:** As a student, I will not enter final exam dates or times because GradePoint will not manage exam scheduling.
